# print-pi

Node.js service เดิมสำหรับ Raspberry Pi/เครื่องคอมพิวเตอร์ยังอยู่ที่ `index.js`

## Android MVP

มีแอป Android สำหรับรับ Pusher event และพิมพ์ผ่าน network printer แทน Raspberry Pi แล้ว ดูวิธี build, ติดตั้ง และ checklist ทดสอบที่ [android-printer/README.md](android-printer/README.md)

Android build นี้เป็น MVP ทางเลือกและยังไม่ได้ลบหรือเปลี่ยน workflow ของ `print-pi` เดิม
